LLM serving · retrieval · test environment

Retrieval-augmented assistant on self-hosted models

The serving platform behind a banking chat assistant. The language model, the embeddings and the vector store are self-hosted, not called from an external model API.

answer path
staged: cheap matches first, and the language model only when they fail
embeddings
an open embedding model, 768 dimensions, served by a text-embeddings inference container
vector store
PostgreSQL with pgvector; session state in Redis Stack
generation
an open-weight 7B model, 4-bit quantised, on a T4 GPU behind an ECS capacity provider
ingest
admin portal → service → queue → container Lambda → embeddings → pgvector; new content is answerable 3–4 s after saving
tuning
match threshold set to 0.75 after measuring that unrelated questions score 0.45–0.60 cosine
latency
~26 s on CPU → about 1–3 s on GPU for generated answers; 0.1–0.3 s for matched answers
ML in production · vision and tabular

Face verification, de-duplication and a segmentation model

The machine-learning services behind customer onboarding and analytics, deployed and run across two clouds.

face match
Amazon Rekognition for face comparison and liveness in the onboarding flow
de-duplication
a face de-duplication service on GCP that checks a new applicant against existing customers
segmentation
BigQuery → feature engineering → K-Means clustering → reviewed labels → random-forest classifier for real-time inference
delivery
Cloud Build pipelines to Cloud Run on GCP; container services on AWS
my part
deployment, pipelines, networking and operations. The models themselves are not my work
Agents · operations · hackathon

Multi-agent incident investigator

Built with two teammates. An incident goes in, a root-cause report comes out.

graph
LangGraph supervisor routing to log, APM, database and scheduler agents, then a root-cause agent
tools
Loki and Prometheus query tools; a Redis event log feeding a live status dashboard
models
an open-weight 8B model on Ollama, with one model file (prompt and parameters) per agent role
runtime
FastAPI service; local stack with tracing, metrics and logs

audit

filtering

safety
read-only by rule and allowlist; the audit was checked afterwards against every script it ran and the cloud audit trail, with no changes found

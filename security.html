Mobile application security · 2026

Reverse engineering and testing a mobile banking app

Threat model: the attacker controls the device. Tested on our own test builds.

Reverse engineering and testing

  • Decompiled the Java layer and analysed the native libraries
  • Mapped the API surface and traced how certificate pinning is wired
  • Built a rooted emulator lab with a runtime instrumentation agent
  • Tested tamper, hook and root detection and SSL pinning
  • Reviewed the in-house security SDK from source
  • Wrote the methodology guide for repeat assessments

Defence design, proposed

  • Dynamic SSL pinning: signed, versioned, expiring pin bundle, rotated without an app release
  • No secrets in the binary: asymmetric encryption or a per-session key
  • App attestation: OS-backed proof exchanged for a short-lived token checked at the gateway
  • Device-bound tokens and per-request signing

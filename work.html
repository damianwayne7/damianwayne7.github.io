Root cause

A service advertised before it was listening

Service discovery published an address before the process accepted connections.

Root cause

A database password that rotated itself

Containers read secrets only at launch, so rotation broke running tasks.

Root cause

Gateway timeouts that were not the load balancer

A database stall cascading through connection pools, proven with a negative control.

Root cause

A function that timed out silently

Memory was the CPU throttle: 2 s locally, over 60 s on the platform.

Root cause

A batch job that more CPU could not speed up

Strictly serial and latency-bound. The fix was a claim step, not a bigger task.

Root cause

"Rename failed: access denied" on uploads

Rename is copy then delete, and the role could not delete.

Root cause

CI jobs queued for a day, then cancelled

Self-updating runners exited mid-assignment. Pinned the version.

Root cause

Deleting a route did not disable the endpoint

A broader prefix route still matched. Read the router source to prove it.

Root cause

A capacity debate about the wrong variable

The limit was keys that never expire, not the engine version.
